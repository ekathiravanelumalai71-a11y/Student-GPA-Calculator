# Student GPA Calculator - Phase 1

This folder is intentionally kept simple for the first phase of the project.

## Purpose

The Phase 1 foundation includes:
- semantic HTML structure
- responsive CSS foundation
- placeholder JavaScript initialization
- student GPA calculator UI shell

## Notes

This project does not include:
- GPA calculation logic
- dynamic subject addition
- local storage
- backend integration
- advanced UI features

The goal is to provide a clean and scalable base for future phases.
